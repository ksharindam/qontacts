
# Qontacts
Simple Contacts Manager application (PyQt based).  

### Description
With this app you can -  
* Save phone numbers and email.  
* Save contact photos.  
* Import vCard v2.1 and v3.0.  
* Export vCard v3.0.  

### Installation

If you want to install using pip, first install these dependencies...  

* python3  
* python3-pyqt6  
* pytqt6-dev-tools (to compile ui files)  

Then inside data/ dir, exec compile_rc. The resource file will be generated.  

Then inside project root directory, run following command..  
`$ sudo pip3 install .`  

To uninstall run..  
`$ sudo pip3 uninstall qontacts`
